# 📁 Python File Rename Utility

A simple, robust, and lightweight Python utility designed to automate bulk-renaming operations on files within a specified directory. Whether organizing media files, sequential documents, or purging cluttered naming conventions, this script handles file path modifications programmatically.

## ✨ Features
* **Batch Processing:** Rename multiple files across an entire directory in a single execution.
* **Targeted Extensions:** Filter and perform renaming logic exclusively on targeted formats (e.g., `.txt`, `.jpg`, `.mp4`).
* **Sequential Numbering:** Automatically append organized, sequential prefixes or suffixes to structure your unstructured datasets.
* **Error Prevention:** Safe execution handling using Python's built-in `os` standard library wrapper to check path validity.
